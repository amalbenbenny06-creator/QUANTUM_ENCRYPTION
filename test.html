Post-Quantum Messaging — Encryption Test

Backend: http://127.0.0.1:8014  |  Plain-text encrypt returns only the ciphertext.

API configuration

1. Provision a recipient key pair — POST /keys

2. Encrypt plaintext — POST /encrypt

Ciphertext will appear here.

3. Send and store a message — POST /conversations/{conversation_id}/messages

This creates a stored message that can be decrypted in step 4. The standalone /encrypt endpoint above does not store a message and does not return a message ID. 

Stored message details will appear here.

4. Decrypt a stored message — POST /conversations/{conversation_id}/messages/{message_id}/decrypt

Decrypted plaintext will appear here.
